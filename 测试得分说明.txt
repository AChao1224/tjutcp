====================================================================
你需要实现的核心逻辑
====================================================================

这是一个完整的用户态 TCP 实现，架构大致如下：

1. 三次握手（establish_connection）
------------------------------------
   客户端 tju_connect：
     发送 SYN 包 -> 状态改为 SYN_SENT
     阻塞等待收到 SYN-ACK -> 发送 ACK -> 状态改为 ESTABLISHED

   服务端 tju_accept：
     阻塞等待 SYN 到达（在 tju_handle_packet 中处理）
     收到 SYN -> 发 SYN-ACK -> 状态 SYN_RECV
     收到 ACK -> 状态 ESTABLISHED，唤醒 accept

2. 可靠数据传输（reliable_data_transfer）
------------------------------------
   tju_send：把数据放入发送缓冲区，启动发送，等待 ACK，超时重传
   tju_recv：从接收缓冲区读取，若为空则阻塞等待
   tju_handle_packet：根据 seq/ack 更新窗口，发送 ACK，去重、排序

3. 四次挥手（close_connection）
------------------------------------
   tju_close：
     发送 FIN -> 状态 FIN_WAIT_1 -> 等待 ACK -> FIN_WAIT_2
     -> 收到对方 FIN -> 发 ACK -> TIME_WAIT -> 等待 2MSL -> CLOSED


====================================================================
关键：tju_handle_packet 是状态机的心脏
====================================================================

所有的报文（SYN、ACK、FIN、数据）都通过
onTCPPocket -> tju_handle_packet 进入你的代码。你需要在这里：

    int tju_handle_packet(tju_tcp_t* sock, char* pkt){
        // 1. 判断是 SYN / ACK / FIN / 数据
        // 2. 根据当前 sock->state 决定如何响应
        // 3. 更新窗口、发送 ACK
        // 4. 唤醒被阻塞的 accept / recv / connect（用条件变量 wait_cond）
    }
